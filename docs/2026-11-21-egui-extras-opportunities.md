**API and dependency findings**

- **Existing use:** TableBuilder is already present in the main pane (`main_pane.rs:96`), library (`library.rs:360`), and history (`history.rs:140`). All have fixed headers and visible-row rendering. Library and history already use stripes. All three already use row interaction senses.
- **Main pane:** Keep its current table structure. Optional text-column resizing has less value here because the title already takes the remaining width. Do not add stripes without checking the selected, played, divider, and on-air states.
- **Size helpers:** Public helpers include `Size::exact`, `initial`, `relative`, `remainder`, `at_least`, `at_most`, and `with_range`. The internal module contains `Sizing`, but the crate exports only `Size`. Do not plan a direct `egui_extras::Sizing` integration.
- **Other table helpers:** `Column::auto`, `auto_size_this_frame`, and `TableBody::heterogeneous_rows` are available. Use explicit initial widths for long text. Keep equal-height rows where that is already the design.
- **Licences:** egui_extras is MIT OR Apache-2.0. Table and strip changes add no dependency family.
- **Syntect:** Version 0.36.2 disables syntect default features and enables `default-fancy`. Thus this dependency path avoids onig. Syntect’s own default is `default-onig`; another dependency could still enable it through Cargo feature unification. Syntect and fancy-regex are MIT. Grammar data, compression, plist/YAML parsing, and regex dependencies still need a check against the resolved lockfile before adoption. [Syntect manifest](https://docs.rs/crate/syntect/5.3.0/source/Cargo.toml), [fancy-regex manifest](https://docs.rs/crate/fancy-regex/0.16.2/source/Cargo.toml).
- **SVG:** resvg 0.45.1 and usvg 0.45.1 inherit **Apache-2.0 OR MIT**. egui_extras disables resvg default features. Its separate `svg_text` feature enables text and system-font support, which adds more dependencies. The resolved transitive licences still require a complete check. [Workspace licence](https://raw.githubusercontent.com/linebender/resvg/v0.45.1/Cargo.toml), [resvg features](https://raw.githubusercontent.com/linebender/resvg/v0.45.1/crates/resvg/Cargo.toml), [usvg features](https://raw.githubusercontent.com/linebender/resvg/v0.45.1/crates/usvg/Cargo.toml).
- **Image features:** `image` alone does not enable PNG/JPEG codecs. `file`, `http`, and decoders serve separate purposes. Avoid `all_loaders` for local cover art because it also enables HTTP and animated formats.
- **Binary size:** No build was run. Size costs above are qualitative estimates. Exact increases and a complete transitive licence audit remain unverified.
- **Project rules:** Keep all dimensions, fonts, and colours in theme tokens. Retain command dispatch for engine changes. Tables and strips do not automatically supply keyboard selection, focus movement, accessible names, or contrast compliance.

2. **Do · M:** Replace the scheduled list’s manual row geometry with TableBuilder cells and a fixed header.
3. **Do · M:** Use StripBuilder to divide space between the four decks and clock.
4. **Do · M:** Add JavaScript highlighting to the Script TextEdit with syntect’s existing fancy-regex configuration.
5. **Do · M:** Use TableBuilder for playlist item lists to align values and render only visible rows.
