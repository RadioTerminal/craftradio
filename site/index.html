Enter a station address, then press Listen.

A station started with --webrtc, or a TinyIce mount such as https://radio.example.com/live.

The sound comes over WebRTC, with about a second of delay, and you install nothing. A station started with --webrtc sends it straight from its own computer. A TinyIce server sends it on to many listeners.

To run a station, start radio --headless --webrtc 8000. It prints the address to share. This page on GitHub Pages can reach a station on your own computer (localhost) or one with an HTTPS address, such as a Cloudflare quick tunnel. On a local network, open the station address itself.
